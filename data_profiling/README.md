# Data Profiling

This folder contains a script for generating and validating a synthetic table with predefined data dependencies.

The generated table is designed to satisfy:

- functional dependencies: `B → C`, `B → D`, `E → A`
- one approximate functional dependency: `A → H` with exactly 5 errors
- minimal unique column combinations: `{G}` and `{F, H}`
- one single-column inclusion dependency: `A ⊂ D`

## Files

- `dependency_constrained_table_generator.py` — generates the synthetic table and validates the required dependencies
- `generated_dependency_table.csv` — example output generated by the script

## Usage

```bash
python dependency_constrained_table_generator.py
